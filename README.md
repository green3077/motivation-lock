# 동기부여 (motivation-lock)

화면을 켤 때 잠금화면 위에 "보물지도" 스타일 코르크판 콜라주(사진 여러 장 + 짧은 문구 포스트잇)를 보여주고, 그 위에 메인 목표 문구가 손글씨로 써내려가는 안드로이드 네이티브 앱입니다.

## 동작 방식

1. `MainActivity`에서 메인 목표 문구(손글씨로 애니메이션될 문장) 1개, 보드에 흩뿌릴 사진 여러 장, 짧은 문구(포스트잇) 여러 개를 설정합니다. 사진/문구는 추가·삭제 즉시 저장되고, 메인 목표 문구만 "저장" 버튼으로 저장합니다.
2. "화면 켤 때 잠금화면에 자동으로 뜨게 하기"를 켜면 `LockScreenTriggerService`(포그라운드 서비스)가 실행되면서 화면 켜짐(`ACTION_SCREEN_ON`)을 감지합니다.
3. 화면이 켜지고 기기가 잠긴 상태면, `Notification.setFullScreenIntent()`를 통해 진짜 시스템 잠금화면(PIN/패턴/지문)보다 먼저 `LockScreenActivity`가 뜹니다(전화/알람 앱과 같은 방식 - 백그라운드에서 직접 Activity를 띄우는 건 Android 10+부터 막혀 있어서 이 방법을 써야 함). `TreasureBoardView`가 사진/포스트잇을 코르크판 위에 살짝 회전된 상태로 흩뿌려 보여주고, 화면을 켤 때마다 메인 목표 문구 손글씨 애니메이션이 처음부터 다시 재생됩니다.
4. 화면 아무 곳이나 탭하면 닫히고, 원래 있던 진짜 잠금화면(또는 잠금이 없으면 홈 화면)으로 이어집니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `MainActivity.kt` | 목표 문구/보드 사진/포스트잇 설정 화면, 잠금화면 미리보기, 자동 실행 스위치 |
| `LockScreenActivity.kt` | 잠금화면 위에 뜨는 실제 화면 |
| `TreasureBoardView.kt` | 사진+포스트잇을 코르크판 위에 회전시켜 흩뿌려 배치하는 커스텀 뷰(내용이 같으면 배치도 고정) |
| `LockScreenTriggerService.kt` | 화면 켜짐을 감지해 `setFullScreenIntent`로 `LockScreenActivity`를 띄우는 포그라운드 서비스 |
| `BootReceiver.kt` | 재부팅 후 자동 실행이 켜져 있었다면 서비스 재시작 |
| `GoalRepository.kt` | 메인 목표 문구/보드 사진 목록/포스트잇 목록 저장·조회 |
| `HandwritingTextView.kt` | 글자를 한 글자씩 드러내는 타이핑 애니메이션 커스텀 뷰 |
| `ImageUtils.kt` | 사진 다운샘플링 디코딩 (setImageURI의 "같은 경로 Uri는 갱신 안 됨" 문제 회피) |

## 알려진 한계

- 일부 제조사(삼성/샤오미 등)의 강한 절전 기능은 배터리 최적화 예외를 줘도 백그라운드 서비스를 종료시킬 수 있습니다 - 100% 항상 뜨는 걸 보장하지는 못합니다. 안 뜨면 기기 설정에서 "자동 실행/보호된 앱" 허용이 추가로 필요할 수 있습니다.
- Android 14(API 34)+에서는 "전체 화면 알림" 권한을 사용자가 설정에서 한 번 더 허용해야 합니다(`MainActivity`가 안내 다이얼로그를 띄움).
- 손글씨 표현은 메인 목표 문구에만 적용되며, v1에서는 나눔손글씨 펜 폰트 + 한 글자씩 나타나는 타이핑 효과입니다. 실제 붓/펜 획이 곡선을 따라 그어지는 진짜 스트로크 애니메이션은 다음 단계 개선 과제입니다.
- 보드 배치는 정교한 드래그 편집이 아니라 칸을 나눠 자동으로 흩뿌리는 방식입니다(내용이 같으면 항상 같은 배치). 실제 코르크 텍스처 이미지 대신 단색 배경으로 표현했습니다.

## 빌드

```
./gradlew assembleDebug
```

이 PC에서는 JDK 경로를 따로 지정할 필요 없이 바로 빌드됩니다(다른 프로젝트인 sobang1004처럼 `gradle.properties`에 특정 PC의 JDK 경로를 박아두지 않았습니다).

release 서명이 필요해지면 `keystore.properties.example`을 참고해 `keystore.properties`를 만드세요.
